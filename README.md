Aplikacija za evidenciju opreme za video igre omogućava jednostavno upravljanje bazom podataka koja sadrži podatke o kategoriji, nazivu, proizvođaču I ceni.
Podaci se mogu unositi, menjati I brisati po potrebi, a mogu se i prikazivati u tabeli prema određenim filterima. Baza podataka za Java aplikaciju u NetBeans razvojnom 
okruženju kreirana je uz pomoć XAMPP Control Panel-a u okviru MySQL-a u phpMyAdmin-u.
